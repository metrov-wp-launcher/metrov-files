# METROV Files

A Metro-style file manager for Android, part of the METROV suite. Browse, copy, move, zip and
clean up your phone, SD card and USB drives, flat and fast.

This repo holds the releases only. Download the APK for your phone from
[Releases](https://github.com/metrov-wp-launcher/metrov-files/releases/latest): most phones
want `arm64-v8a`.

No internet permission, no account, no analytics or ads: your files never leave the phone.
